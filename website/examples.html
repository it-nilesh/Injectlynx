Live examples

See Injectlynx in the application shapes developers ship every day.

Each sample is a buildable project in the repository, using the same main package and generated Microsoft DI registrations.

Minimal API

Conventions plus member injection

Matching interfaces, open generics, property injection, method injection, and generated startup registration.

dotnet build samples/MinimalApi/MinimalApi.csproj -f net10.0
Open sample
Web API

Advanced registration rules

Custom generated methods, keyed services, decorators, external services, and architecture rules.

bash eng/validation/validate-webapi-sample.sh
Open sample
Worker Service

Hosted worker dependencies

Generated application-service registrations inside a background worker project.

bash eng/validation/validate-worker-service-sample.sh
Open sample
Native AOT

No runtime scanning path

Direct generated registrations for trimming-sensitive and Native AOT deployments.

bash eng/validation/validate-native-aot.sh linux-x64 net10.0
Open sample
Dynamic plugins

Opt-in runtime extension

Loads a plugin DLL that implements IInjectlynxPlugin without a required JSON manifest.

dotnet run --project samples/PluginHost/PluginHost.csproj -f net10.0 -- samples/PluginSample/bin/Debug/net10.0
Open sample
